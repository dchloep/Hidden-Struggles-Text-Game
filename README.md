# Hidden Struggles of a Mother

This project is a Python text-based adventure game where the player explores different rooms, collects seven special items, and prepares to face the final villain, the Crushing Weight. Each room and item represents a different struggle or challenge that comes with motherhood.

The goal is to collect all seven items before entering the final room. If the player collects everything, they defeat the Crushing Weight and win. If they enter without all seven items, they lose.

## Features

- Navigate between connected rooms using directional commands
- Collect items and store them in an inventory
- View the current room, inventory, and available directions
- Use text commands to interact with the game
- Experience different endings depending on the items collected
- Win or lose based on the player's decisions

## Technologies Used

- Python
- Pycharm

## How to Play

1. Run `TextGame.py` using Python.
2. Follow the instructions displayed at the beginning of the game.
3. Type commands such as `go north` or `go east` to move between rooms.
4. Collect items using commands such as `get Sleep Feather`.
5. Collect all seven items before entering Mind Room to defeat the Crushing Weight.
